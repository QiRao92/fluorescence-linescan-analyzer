# Fluorescence Line-scan Analyzer

双击 `open_HNF4A_analyzer.bat` 打开完整分析界面。

## 基本流程

1. 点击“导入图片”选择一张或多张合并图，也可以点击“导入文件夹”。
2. 检查右侧像素尺寸。软件会优先读取 ZEISS XML；无法读取时可手动输入。
3. 输入两条待分析信号的名称，例如 HNF4A、DAPI、AFP 或 Hoechst。
4. 点击“① 绘制/编辑 ROI”，在中间图像上按住左键拖动。
5. 框选后可拖动 ROI 内部移动，也可拖动边和角的控制点调整大小；按 Enter 完成。
6. 如需精确尺寸，在 ROI 宽和高中输入 µm 数值，再点击“应用输入的 ROI 长宽”。
7. 点击“② 画扫描线”，在黄色 ROI 内依次点击起点和终点。
8. 点击“③ 生成曲线”，右侧显示两条自定义信号的 intensity profile。
9. 点击“导出当前”或“批量导出全部”。

## 图像与通道

- 对项目现有的 `c1-3.tif` 合并图，软件会自动寻找同目录的 `c1`、`c2`、`c3` 图。
- 当前数据来源：c1 = F-actin，信号1读取 c2/红色通道，信号2读取 c3/蓝色通道。
- 信号1和信号2的名称可以自由输入，并可一键应用到全部导入图片。
- 导入普通 RGB 图时，信号1读取红色通道，信号2读取蓝色通道，绿色通道用于 F-actin 预览。
- 图像上方可以单独开关三个通道，仅影响预览，不改变分析数据。

## ROI 与分析参数

- 默认使用自由矩形 ROI，拖多大就分析多大。
- 框选后 ROI 保持可编辑状态：拖动框内移动，拖动边或角调整长宽。
- ROI 宽度和高度可以分别手动输入；“应用输入的 ROI 长宽”会围绕当前 ROI 中心调整，并确保不超出图像。
- 默认扫描带宽为 1.5 µm，平滑 σ = 1.2，背景扣除使用 ROI 内第 1 百分位数。
- 更改像素尺寸或分析参数后，需要重新点击“生成曲线”。

## 导出内容

每张已分析图像会导出：

- `*_profile.csv`：距离和两条自定义信号的数值，CSV 表头使用输入的名称；
- `*_overlay.png`：完整原图、黄色 ROI 和白色扫描线，用于定位；
- `*_ROI_composite.png`：ROI 裁剪后的合并图；
- `*_ROI_composite_overlay.png`：ROI 合并图及白色扫描线；
- `*_ROI_F-actin.png`：ROI 内 F-actin/c1 单通道图；
- `*_ROI_信号名称.png`：ROI 内信号1/c2和信号2/c3单通道图；
- `*_ROI_channels_panel.png/.pdf`：合并图和三个单通道的四宫格展示；
- `*_curve.png` 与 `*_curve.pdf`：曲线图；
- `*_analysis_panel.png`：ROI 局部图与曲线组合图；
- `*_analysis.json`：像素尺寸、ROI、扫描线和通道说明。

当前输入是 ZEISS 导出的 8-bit 伪彩色 TIFF，线扫描适合作为空间共定位的展示性分析。严格的样本间荧光强度比较应优先使用原始 CZI/16-bit 数据。
