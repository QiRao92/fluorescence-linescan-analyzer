# FluoQuant

双击 `open_FluoQuant.bat` 打开完整分析界面。

## 基本流程

1. 点击“导入图片”选择一张或多张合并图，也可以点击“导入文件夹”。
2. 检查右侧像素尺寸。软件会优先读取 ZEISS XML；无法读取时可手动输入。
3. 点击“添加分析通道”，在弹窗中选择图像通道来源、输入名称并设置颜色；主界面仅保留紧凑摘要，可继续添加更多通道。
4. 输入 ROI 宽和高，点击“按输入尺寸生成可调 ROI 框”。
5. 生成后可拖动 ROI 内部移动，也可拖动边和角的控制点调整大小；按 Enter 完成。
6. 点击“② 画扫描线”，在黄色 ROI 内依次点击起点和终点。
7. 点击“③ 生成曲线”，右侧显示所有已添加信号的 intensity profile。
8. 点击“导出当前”或“批量导出全部”。

## 图像与通道

- 支持直接打开 ZEISS 原生 `.czi` 文件：通道名、ZEN 显示颜色、像素标定自动从内嵌元数据读取，曲线使用原始（如 16-bit）强度值，是定量分析的首选输入。多维数据（Z-stack、Airyscan 相位等）取第一层。
- 软件可识别 RGB、灰度、多通道 TIFF，以及同目录的 `c1…cN` 独立通道图（`_c1-3`、`_c1-4` 等任意通道数的 ZEISS 命名均可）。
- PNG 会按原始颜色无损显示；带透明度（RGBA）或调色板模式的 PNG 会自动转为真彩色，透明度通道不会被当作信号。
- 软件不预设任何生物学通道名称，只显示 R/G/B、c1/c2/c3 或“通道 1…n”等客观来源。
- 每个分析通道都需要操作者选择来源并输入名称；可按图像通道数量继续添加。
- 点击每行的“颜色”按钮可自定义伪彩色，并同步用于主图预览、曲线和导出单通道图。
- 曲线图例、CSV 表头、导出文件名和参数 JSON 会使用操作者输入的名称。
- 图像上方可以单独开关所有可用来源通道，仅影响预览，不改变分析数据。
- 滚轮以鼠标位置为中心缩放图像；空闲状态下左键拖动平移、双击复位，ROI/扫描线模式下用中键拖动平移。缩放仅影响查看，不改变分析数据。

## ROI 与分析参数

- ROI 宽度和高度可以分别手动输入；点击一个按钮即可生成对应尺寸的 ROI。
- 新生成的 ROI 立即保持可编辑状态：拖动框内移动，拖动边或角调整长宽。
- 默认扫描带宽为 1.5 µm，平滑 σ = 1.2，背景扣除使用 ROI 内第 1 百分位数。
- 勾选“SD 误差带”后，会沿扫描带宽方向计算每个采样点的标准差：曲线显示均值 ± SD 的半透明误差带，CSV 增加 `*_SD` 列。带宽为 1 px 时无法计算 SD。
- 更改像素尺寸或分析参数后，需要重新点击“生成曲线”。

## 导出内容

两个模块的导出面板都提供内容勾选：只导出勾选的文件（未勾选的不会生成），勾选状态会在下次启动时保留。每张已分析图像可导出：

- `*_profile.csv`：距离和所有已添加信号的数值，CSV 表头使用输入的名称；启用 SD 时每个信号后附 `*_SD` 列；
- `*_overlay.png`：完整原图、黄色 ROI 和白色扫描线，用于定位；
- `*_ROI_composite.png`：ROI 裁剪后的合并图；
- `*_ROI_composite_overlay.png`：ROI 合并图及白色扫描线；
- `*_ROI_信号名称.png`：每个已添加分析通道各自的 ROI 单通道图；
- `*_ROI_channels_panel.png/.pdf`：根据分析通道数量自动排版的合并图与单通道展示；
- `*_curve.png` 与 `*_curve.pdf`：曲线图；
- `*_analysis_panel.png`：ROI 局部图与曲线组合图；
- `*_analysis.json`：像素尺寸、ROI、扫描线和通道说明。

## 细胞分割模块

右侧"细胞分割"标签页是独立于线扫描的分析模块：

- **分割模式**：
  - 单通道（核/对象）：只分割一个通道里的对象，胞质用向外扩环近似；
  - 双通道（核 + 胞体）：核通道（DAPI）分核 + 胞体通道（如 F-actin）勾勒细胞边界，得到真实的细胞/核/胞质三区室。CSV 增加 `cell_area_um2 / nucleus_area_um2 / cyto_area_um2 / nc_area_ratio`（核质面积比），并对**全部通道**自动给出 `*_cell_mean / *_nuc_mean / *_cyto_mean / *_nuc_cyto_ratio`（区室现成，无需勾选，核周环参数在此模式下隐藏）；图像上黄色为细胞边界、青色为核边界；标签掩膜额外导出 `*_labels_nuclei.tif`。组织切片等密集样品建议用 Cellpose；双通道模式下"目标直径"指细胞直径（经典方法用它限制从核向外的扩展范围）。
- **分割通道**：选择核染色（DAPI/Hoechst 会自动选中）；双通道模式再选一个胞体通道（自动优先 actin/膜染色类名称）。
- **方法**：经典（Otsu 阈值 + 分水岭，秒级，无需额外依赖）或 Cellpose（深度学习，需 `pip install cellpose`，支持 GPU 加速）。
- **参数**：最小面积过滤；经典方法的平滑尺度；Cellpose 的目标直径（高分辨率图像强烈建议填写，肝细胞核约 10 µm，设 0 为自动）。
- **范围**：可勾选"仅分割当前 ROI 区域"（大图推荐，速度快且便于核对）。
- 运行后黄色边界叠加在图像上（可开关），计算在后台线程执行，不阻塞界面。
- **结果概览**：分割完成后直接显示细胞数、密度、面积均值±SD、各通道强度均值和核/质比均值，以及面积分布与核/质比分布直方图（优先展示已命名的分析通道）；切换图像时概览跟随更新。
- **导出**：单细胞 CSV + 标签掩膜 TIF（cell_id 与 CSV 对应；TIF 存的是编号所以直接看是黑的，配套的 `*_labels_colored.png` 是伪彩色预览版）+ 边界 Overlay PNG + 参数/汇总 JSON。导出完成后自动打开导出文件夹。导出弹窗除了选文件，还可以按组勾选**包含的指标**（基本形态 / 形态细节 / 强度统计 / 区室指标；细胞编号、质心和各通道 mean 始终包含），选择会被记住并写入 JSON 的 `metric_groups` 字段。CSV 每行一个细胞，完整指标包含：
  - 形态：质心坐标（µm）、面积（µm²）、等效直径、周长、圆度（4πA/P²）、长宽比、实度（solidity）；
  - 每个通道的强度：mean / median / max / integrated（配置过分析通道名称的列用该名称）；
  - 核/核周比（可选，单通道模式）：在"核/核周比通道"里勾选需要该指标的通道（默认不勾选）。对勾选的通道，以分割对象（通常为核）向外扩"核周环"（宽度可调，默认 1.5 µm）作为胞质的近似，给出核周环均值 `*_perinuclear_mean` 和核/核周强度比 `*_nuc_peri_ratio`（如 HNF4A 入核程度的近似指标）。注意这不是严格的核/质比——需要真实核/质比时请用双通道分割模式（`*_nuc_cyto_ratio`）。
  - JSON 里附带汇总统计：细胞计数、密度（个/mm²）、平均面积/圆度、各通道强度与核质比的均值。

当前输入是 ZEISS 导出的 8-bit 伪彩色 TIFF，线扫描适合作为空间共定位的展示性分析。严格的样本间荧光强度比较应优先使用原始 CZI/16-bit 数据。
